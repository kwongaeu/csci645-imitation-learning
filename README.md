# CSCI 645 Homework 2

Imitation learning for PandaPickCube using state observations and ACT.

## Experiment
- Baseline: approximately 100 demonstration trajectories.
- Ablation: fixed subset of 25 trajectories.
- Evaluate both policies on the same 50 held-out initializations.

## Project structure
- code/: collection, training, and evaluation code
- configs/: experiment settings, seeds, and dependency records
- results/: evaluation summaries and figures
